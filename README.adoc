== 📘 Описание проекта
Проект реализует обработку и анализ пользовательских событий из e-commerce датасета Kaggle.

Пайплайн состоит из трёх слоёв:
* *Raw* — исходные данные (CSV)
* *Staging* — очищенные данные (Parquet)
* *Mart* — аналитические витрины (CSV)

== ⚙️ Технологический стек
|===
| Компонент | Технология | Назначение

| Язык
| Python 3.10+
| Основная реализация ETL

| Библиотеки
| pandas, boto3, pyspark, sqlalchemy
| Очистка и агрегация данных

| Хранилище
| S3 / HDFS
| Data Lake для хранения слоёв

| DWH
| PostgreSQL / ClickHouse
| Аналитическое хранилище

| BI
| Power BI / Superset
| Визуализация данных
|===

== 🚀 Установка и запуск

[source,bash]
----
# Клонировать проект
git clone https://github.com/TLUMSY/big-data.git
cd big-data

# Создать виртуальное окружение
python -m venv venv
venv\Scripts\activate

# Установить зависимости
pip install -r requirements.txt
----

[source,bash]
----
# Очистить и обработать данные
python scripts/clean_staging.py

# Создать витрины
python scripts/create_marts.py
----
