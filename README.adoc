== 📘 Project Description
This project processes and analyzes user events from a Kaggle e-commerce dataset.

The pipeline consists of three layers:

* *Raw* — source data (CSV)
* *Staging* — cleaned data (Parquet)
* *Mart* — analytical data marts (CSV)

== ⚙️ Technology Stack
|===
| Component | Technology | Purpose

| Language
| Python 3.10+
| Core ETL implementation

| Libraries
| pandas, boto3, pyspark, sqlalchemy
| Data cleaning and aggregation

| Storage
| S3 / HDFS
| Data Lake for storing the layers

| DWH
| PostgreSQL / ClickHouse
| Analytical storage

| BI
| Power BI / Superset
| Data visualization
|===

== 🚀 Installation and Usage

[source,bash]
----
# Clone the repository
git clone https://github.com/TLUMSY/big-data.git
cd big-data

# Create a virtual environment
python -m venv venv
venv\Scripts\activate

# Install dependencies
pip install -r requirements.txt
----

[source,bash]
----
# Clean and process the data
python scripts/clean_staging.py

# Build the data marts
python scripts/create_marts.py
----
